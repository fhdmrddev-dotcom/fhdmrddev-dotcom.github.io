Privacy Policy

Fudool Studio. Last updated: 8 October 2026.

Fudool Studio is a personal tool that runs only on its owner's own computer. It has no servers, no user accounts and no other users. This page explains what it does with Google user data.

What data it accesses

Only when the owner links their own YouTube channel, and only with these read-only permissions:

  • YouTube Data API (youtube.readonly): the channel's name and its list of videos with their public statistics.
  • YouTube Analytics API (yt-analytics.readonly): the channel's own performance numbers, such as views, watch time and click rate.

How the data is used

The numbers are shown to the owner inside the studio, with plain tips about which of their own videos work best. The studio never uploads, edits, deletes or posts anything on YouTube.

Where the data is stored

Everything is stored on the owner's own computer: the numbers in local files, and the sign-in token in a local settings file. There is no developer server; nothing is sent to the developer.

To write the tips, the studio sends a short summary of the channel's numbers (never the sign-in token) to the AI model the owner has set up in the studio (for example Anthropic's Claude). That provider handles it under its own terms, only to write the tips for the owner.

Sharing

Apart from the tip summary above, Google user data is not shared with anyone. It is not sold, not used for advertising, and the studio does not use it to train AI models.

Removing access and deleting data

The owner can unlink the channel inside the studio at any time, which deletes its saved token. Access can also be removed at myaccount.google.com/permissions. The local files can be deleted from the computer at any time.

Google API Services User Data Policy

Fudool Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
